# Getting help

- **Questions, setup help and discussion:** join the [OunceMCP Discord](https://discord.gg/mQz4ZuZe3u) and post in `#help`, one post per question. Include your OunceMCP, Python and FastMCP versions, the smallest code that shows the problem, and the full error.
- **Documentation and The OunceMCP Book:** https://subbusainath.github.io/ouncemcp/
- **Bugs and feature requests:** open a [GitHub issue](https://github.com/subbusainath/ouncemcp/issues/new/choose).
- **Security vulnerabilities:** never post them on Discord or in an issue. Report them privately, as [SECURITY.md](SECURITY.md) describes.

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
