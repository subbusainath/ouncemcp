# Governance

OunceMCP is maintained by its founding maintainer, Subbusainath Rengasamy, until additional maintainers are added.

- **Decisions:** Day-to-day changes are decided in pull requests. Changes to the public API or default behavior require a design proposal in `docs/proposals/`.
- **Maintainers:** Contributors with sustained, high-quality contributions may be invited to become maintainers.
- **Upstream alignment:** The project tracks the MCP specification and FastMCP, and adopts official mechanisms (such as progressive discovery) when they are specified.
